## 三、核心加班计算规则

系统核心公式：

```txt
加班时长 = 实际有效出勤时长 - 工作日出勤天数 * 8小时
````

但是需要严格按以下业务规则计算：

### 默认工作时间

```txt
上班时间：09:30
下班时间：19:00
标准工作时长：8小时
加班开始时间：19:00
```

### 规则 1：9:30 之前打卡不算额外工时

例如：

```txt
08:50 打卡上班，也只能从 09:30 开始算有效出勤
```

也就是：

```txt
有效上班时间 = max(实际上班打卡时间, 09:30)
```

### 规则 2：只有 19:00 之后才算加班

例如：

```txt
18:50 下班，不算加班
19:30 下班，只算 19:00 - 19:30 的 30 分钟加班
```

也就是：

```txt
当日加班分钟数 = max(0, 实际下班时间 - 19:00)
```

### 规则 3：每日有效出勤

```txt
有效出勤时长 = 实际下班时间 - max(实际上班时间, 09:30)
```

### 规则 4：月度统计

月度统计需要支持：

* 总出勤天数
* 总实际有效出勤时长
* 总标准工作时长
* 总加班时长
* 平均每日加班时长
* 最大单日加班时长
* 最小单日加班时长
* 迟到次数
* 早退次数
* 异常打卡次数
* 周维度趋势
* 日维度趋势

### 规则 5：异常处理

以下情况需要标记异常：

* 缺少上班打卡
* 缺少下班打卡
* 下班时间早于上班时间
* 日期格式异常
* Excel 行数据无法解析
* 同一天有多条记录时，需要支持合并或提示冲突

### 规则 6：展示格式

所有分钟数需要支持格式化：

```txt
90分钟 => 1小时30分钟
30分钟 => 30分钟
480分钟 => 8小时
```

同时保留小数小时格式：

```txt
90分钟 => 1.5小时
```

请封装通用工具函数：

* parseTime
* parseExcelDate
* calculateDailyAttendance
* calculateMonthlyReport
* formatMinutes
* minutesToDecimalHours
* groupByMonth
* groupByWeek
* validateAttendanceRow

所有核心计算逻辑必须有单元测试或至少提供测试用例数据。
